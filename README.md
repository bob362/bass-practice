# ベース練習アプリ

ブラウザベースのベース練習用アプリケーションです。タブ譜の表示、再生、速度調整、A-Bループ機能、**PDFタブ譜のインポート**を備えています。

## 特徴

- 📊 **タブ譜の表示**: Guitar ProファイルやMusicXMLファイルを読み込んで、リズムが見やすいタブ譜を表示
- 📄 **PDFインポート（NEW!）**: PDFのベースタブ譜を読み込んで演奏可能なタブ譜に変換
  - テキストベースPDF: 高精度で自動認識
  - スキャン画像PDF: OCR（光学文字認識）で抽出
  - レビュー・編集機能: 認識結果を確認・修正してから保存
  - 元のPDFを練習画面に並べて表示可能
- 🎵 **音源再生**: シンセサイザー音源でベースラインを再生
- 🎯 **クリック再生**: タブ上の任意の位置をクリックして、その場所から再生開始
- ⚡ **速度調整**: 50%〜120%の範囲でテンポを調整（ゆっくり練習→徐々にスピードアップ）
- 🔁 **A-Bループ**: 難しいフレーズを指定した区間で繰り返し練習
- 💾 **曲の管理**: 変換したPDFタブ譜をブラウザに保存・管理
- 🎸 **ベース特化**: 4弦ベース（標準チューニング E A D G）に最適化

## 使い方

### 1. PDFタブ譜のインポート（新機能！）

#### ステップ1: PDFをアップロード

1. アプリを開いて **「曲の管理」** タブをクリック
2. **「+ 新しいPDFをインポート」** ボタンをクリック
3. PDFファイルをドラッグ&ドロップ、または選択ボタンからアップロード

#### ステップ2: レビュー・編集

- PDFから自動抽出されたタブ譜データが表示されます
- **曲名**、**アーティスト**、**テンポ**を編集できます
- 各小節のデータを確認・修正できます（形式：`フレット番号.弦番号`）
  - 例：`0.4 3.4 5.3` = 4弦0フレット、4弦3フレット、3弦5フレット
- 小節の追加・削除も可能
- **「保存して使用」** をクリックして保存

#### ステップ3: 練習

1. 保存した曲が「曲の管理」リストに表示されます
2. 曲をクリックすると練習画面に移動
3. **「📄 PDFを表示」** ボタンで元のPDFを横に表示できます
4. 再生、テンポ調整、A-Bループを使って練習

#### 対応するPDF形式

- **Guitar Pro / Songsterr 形式のPDF**（標準記譜＋4線タブ）
  - ドロップDなどのチューニング表記、テンポ、フレット、弦の位置、小節線を読みます
  - ハンマリング（H）、スライド（sl.）、デッドノート（X）も拾える場合があります
  - 音価は連桁と休符から推定します。8分音符の繰り返しは比較的合い、16分や付点、タイはずれることが多いです
  - 小節線を取りこぼすと、隣の小節とつながって長くなります。レビュー画面で直してください
  - 実測（5ページ・約100小節の Guitar Pro 書き出し）: 小節は 93/104。フレットと弦は小節が分かれているときおおよそ 85%。リズムは全体のおよそ半分（8分のグルーヴは合い、16分の塊と休符は外れやすい）。H / sl. / X は印が同じ弦の音のあいだにあるときだけ付きます
- **テキストのASCIIタブ**（`G|---5---` のようなPDF）
  - 行として読める場合はフォールバックで読みます。音価は均等です

- **スキャン画像PDF** - OCRで認識（精度は中程度）
  - 紙のタブ譜をスキャンしたPDF
  - 画像として保存されているPDF
  - OCR（光学文字認識）で自動抽出
  - レビュー画面で必ず内容を確認・修正してください

### 2. サンプル曲の再生

アプリに同梱されているサンプル曲で機能を試せます。

1. **再生ボタン** をクリックして演奏を開始
2. タブ譜上の任意の位置をクリックすると、そこから再生開始
3. **テンポスライダー** で速度を調整

### 3. 自分のファイルを読み込む（Guitar Pro / MusicXML）

1. 右側のコントロールパネルの **「ファイル読み込み」** セクションで **「ファイルを選択」** をクリック
2. Guitar Pro ファイル（.gp, .gp5, .gpx）または MusicXML ファイル（.musicxml, .xml）を選択
3. タブ譜が自動的に表示されます

### 4. A-Bループで反復練習

難しいフレーズを集中的に練習する方法：

1. 再生を開始し、練習したい区間の **始点** で **「A地点を設定」** をクリック
2. 区間の **終点** で **「B地点を設定」** をクリック
3. **「ループ開始」** をクリックすると、A〜B区間が繰り返し再生されます
4. テンポを下げて練習し、慣れてきたら徐々に上げていきましょう

## 対応ファイル形式

### PDFタブ譜
- **PDF** (.pdf) - テキストベースまたはスキャン画像

### 楽譜ファイル
- **Guitar Pro**: .gp, .gp3, .gp4, .gp5, .gpx
- **MusicXML**: .musicxml, .xml

Guitar Proファイルは[Guitar Pro](https://www.guitar-pro.com/)や[TuxGuitar](https://tuxguitar.softonic.jp/)などのソフトウェアで作成できます。

## 技術的な制約とヒント

### PDFインポートについて

- **テキストベースPDFが最も精度が高い**です。可能な限りテキスト情報を含むPDFを使用してください。
- スキャン画像PDFは**OCRの精度に限界**があります。必ずレビュー画面で内容を確認してください。
- 複雑なレイアウトや手書きタブ譜は認識精度が下がる場合があります。
- PDFから抽出されたデータは**ブラウザのlocalStorageに保存**されます（ブラウザデータをクリアすると消えます）。

## よくある質問

### PDFが正しく認識されません

- テキストベースのPDFを使用していますか？画像PDFはOCRの精度に限界があります。
- レビュー画面で抽出されたデータを確認し、必要に応じて修正してください。
- フレット番号が正しく表示されているか確認してください。

### 保存した曲が消えました

- ブラウザのデータ（Cookie、キャッシュ、localStorage）をクリアすると保存した曲も削除されます。
- ブラウザのプライベートモードでは曲が保存されません。

### 再生速度を変えると音がおかしくなります

- これはalphaTabの仕様です。極端に遅いまたは速い速度では音質が劣化する場合があります。
